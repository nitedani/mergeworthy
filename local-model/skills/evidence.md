## Instructions
Build the strongest evidence-backed case for the Position: what the code does (`path:line`), what `main` does for the analogous case, a measurement where one is possible. Also list the weakest points of this side.

## Ticket
- Goal: the decision the debate is about.
- Position: the side to argue.
- Facts, To check, Scope: as for facts.
